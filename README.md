# 🎭 Role Assigner (完全GUI・おまかせ役職自動割り当てツール)

メンバーから提出された希望順位をもとに、各役職の定員に合わせて自動で均等に割り振るツールです。
GitHubの「Issueフォーム」の仕組みを利用しており、PCやスマホのブラウザ上でフォームを入力するだけで、誰でも簡単に均等な割り振りが実行できます。

---

## ✨ このツールの強み
- **完全ブラウザ完結**: ソースコードや設定ファイルを一切触らずに実行できます。
- **同率順位に対応**: 「A役もB役もどちらも1位」といった柔軟な希望提出が可能です。
- **選べる2つの割り当てモード**: 
  1. **ワースト回避モード (`fairness_first`)**: 「第4希望」などの大ハズレを引く人を最小限に抑え、全員が平均して高い満足度になるようパズルを解きます。
  2. **第1希望最優先モード (`satisfaction_first`)**: とにかく第1希望が通る人の数を最大化します（漏れた人は下位希望に回りやすくなります）。

---

## 🚀 使い方（3ステップで完結）

### 1. フォーム画面を開く
1. リポジトリ上部のメニューにある **「Issues」** タブをクリックします。
2. 右上にある緑色の **「New issue」** ボタンをクリックします。
3. 『🎭 役職自動割り当て (GUIフォーム)』という項目の右側にある **「Get started」** ボタンをクリックします。

### 2. データの編集と送信
画面に複数行入力できる専用のフォームが開きます。最初からサンプルデータが入力されているので、あなたの組織の条件に合わせて自由に書き換えてください。

- **1. 割り当てモードを選択**: ドロップダウンからお好みの方針を選択します。
- **2. 各役職の定員**: 役職名と定員の数値を編集します（例: `HO1: 1`）。
- **3. メンバーの希望順位**: メンバーの名前と希望順位を編集します（例: `Member1: {HO1: 2, HO2: 1}`）。
  ※行を増やしたり減らしたりしても自動で認識されます。

編集が終わったら、画面右下にある緑色の **「Create issue」**（または **「Create」**）ボタンをクリックします。

### 3. 結果の確認（約10秒後）
ボタンを押すと、裏側で自動計算システム（GitHub Actions）が起動します。

1. 送信後、**約10秒ほど待ってからページをリロード（再読み込み）** します。
2. 画面の下の方に、自動計算された**綺麗なマークダウン表の結果**が自動で返信（コメント）されます。
3. 確認が完了すると、この画面（Issue）はシステムによって自動的にクローズ（終了処理）されるため、ログが散らかる心配もありません。

---

## 🛠️ 事前準備（リポジトリ作成者のみ）
このツールを自分のGitHubリポジトリで初めて動かす際は、以下の設定を1度だけ行ってください。

1. リポジトリの **「Settings」** タブ ＞ 左メニューの **「Actions」** ＞ **「General」** を開きます。
2. 画面一番下の **「Workflow permissions」** で **「Read and write permissions」** にチェックを入れて保存します。
   ※これにより、プログラムが自動で結果を書き込めるようになります。
