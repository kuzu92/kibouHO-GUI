# Role Assigner (完全GUI対応版)

ファイルを直接書き換えることなく、GitHubの画面上でデータを貼り付けるだけで役職を自動割り当てできるツールです。

## 🚀 使い方

### 1. フォームを開く
1. リポジトリ上部の **「Issues」** タブをクリックします。
2. 緑色の **「New issue」** ボタンをクリックします。
3. 「🎭 役職自動割り当て (GUIフォーム)」の右側にある **「Get started」** ボタンをクリックします。

### 2. 条件の入力
綺麗なフォーム画面（複数行入力対応）が開きます。
- モードの選択（ドロップダウン）
- 各役職の定員（複数行入力可）
- メンバーの希望順位（複数行入力可）
を入力・貼り付けし、一番下の **「Submit new issue」** ボタンを押します。

### 3. 結果の確認
ボタンを押すと自動的に計算が始まります。**約10秒ほど待ってからページをリロード（再読み込み）** すると、画面下部のコメント欄に「役職の割り当て結果」の表が自動で投稿され、確認することができます。
