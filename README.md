# Role Assigner (GUI対応・自動役職割り当てツール)

GitHubの画面上だけで、希望順位をもとに各役職へ自動で均等に割り振るツールです。ソースコードや設定ファイルを一切編集することなく、ブラウザからの入力だけで動作します。

## 🚀 使い方（ブラウザ上で3ステップ実行）

### 1. 実行画面を開く
1. リポジトリ上部の **「Actions」** タブをクリックします。
2. 左側のメニューから **「Execute Role Assignment (GUI)」** を選択します。
3. 右側にある **「Run workflow」**（緑色のボタン）をクリックすると、入力フォームが開きます。

### 2. 条件を入力する
ポップアップ内の各項目を選択・入力します。
- **モード選択**: `fairness_first`（誰も不満にならないワースト回避）か、`satisfaction_first`（第1希望を極力通す）を選択。
- **役職の定員**: 各役職の定員を記入（例: `A役: 2`）。
- **メンバーの希望順位**: 以下の形式でメンバーの希望を入力（同率順位も可能）。
  ```yaml
  佐藤: {A役: 1, B役: 1, C役: 2}
  鈴木: {A役: 1, B役: 2, C役: 3}
  ```

### 3. 結果を確認する
1. 緑色の **「Run workflow」** ボタンを押して実行します。
2. 数十秒待つと処理が完了するので、新しくできた実行履歴をクリックします。
3. 画面下部の **「Artifacts」** にある `assignment-result` から結果（テキストファイル）をダウンロードするか、ログの「Run assignment script」を開いて画面上で結果を確認できます。
